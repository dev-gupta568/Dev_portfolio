# Dev Gupta Portfolio

A modern personal portfolio website built with React, Vite, and Express. This project showcases projects, skills, and contact information in a clean interactive design with animations and responsive layout.

## Overview

This portfolio is designed for a developer profile and includes:

- Hero section with introduction and call-to-action
- Skills and technologies section
- Project showcase cards
- Contact form connected to a backend API
- Responsive layout for desktop and mobile devices
- Animated effects and smooth UI transitions

## Tech Stack

- Frontend: React + Vite
- Styling: Custom CSS
- Backend: Node.js + Express
- Database: MongoDB
- Security: Helmet and rate limiting
- Animations: Anime.js

## Project Structure

```bash
Dev_portfolio/
├── public/              # Static assets and resume
├── server/              # Express backend API
├── src/                 # React app source files
├── index.html           # App entry point
├── package.json         # Scripts and dependencies
├── vite.config.js       # Vite configuration
└── README.md            # Project documentation
```

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the frontend

```bash
npm run dev
```

### Run the backend server

```bash
npm run server
```

## Environment Setup

Create a `.env` file in the project root if needed for backend configuration, such as:

```bash
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```
